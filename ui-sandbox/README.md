# Fenix AOS UI Sandbox

独立的控制台 UI/UX 设计沙盘。所有内容均为本地 Mock 数据，不调用主项目 API，不依赖鉴权，也不修改 `web/` 的路由或业务代码。

## 运行

```bash
cd ui-sandbox
bun run dev
```

默认地址：`http://127.0.0.1:5174/`。页面使用 Hash 路由，例如 `/#models`、`/#workflow`、`/#chat`。

生产构建：

```bash
bun run build
```

## 页面清单

- 核心：首页、Chat 设计、智能体编排、沙盒模版
- 配置：模型库、技能库、知识库、插件市场、定时任务、记忆、应用部署、组织、API Key

Chat 页面包含普通对话、超长会话、104 次工具调用、Markdown、Ask User、Todo / 子任务 / 改动状态、Plugin 和文件预览等场景。

## 设计原则

- 亮色界面，蓝色作为唯一主色调。
- 内容面保持白色，状态色只表达成功、等待和失败。
- 减少边框，以留白、层级和浅色表面组织信息。
- 每个页面根据业务对象使用独立结构，不用同一张模板表格替代全部页面。
