# 工作区文件选择与整理

## 已确认交互

1. 单击文件选中并预览；单击目录保持当前展开行为。
2. Cmd/Ctrl + 单击切换多选；Shift + 单击按可见顺序连续选择。修饰键选择不切换预览、不展开目录。
3. 只用行高亮表示选择，不增加复选框、选择计数栏、批量工具栏或框选。
4. 从选中行拖动整组，从未选中行拖动该单项；放到目录或分区根目录完成移动。目标目录高亮，不支持同级排序。
5. 右键打开菜单：右键已选项保留整组，右键未选项先切换为单选；点击菜单中的删除后打开确认框，确认后才调用接口。取消不修改文件。
6. 多选菜单只提供适用于整组的删除；单选保留既有引用、下载、重命名、移动和创建入口。删除不再占用行内悬浮按钮。
7. 点击树内空白或按 Escape 清除选择；搜索词变化清除选择，避免隐藏文件被意外删除；刷新保留仍存在的选择，切换环境清空全部交互状态。

## 边界与职责

- 公共文件树组件只处理渲染、选择手势和原生拖动事件，不调用文件 API。
- Machine 文件容器持有双分区共享的选择与菜单状态；独立 hook 编排删除、移动和局部失败，已有输入弹窗编排按职责抽离，单文件不超过 500 行。
- 使用已有 react-arborist 虚拟化、键盘焦点和展开能力；原生 HTML5 拖动支持两个树之间移动，使用专用 MIME 和环境作用域区分文件移动与外部上传。
- 复用现有 rename 和 batchDelete API，不新增数据库结构、第三方依赖或后端协议。
- 服务端继续负责环境授权、workspace 路径与符号链接边界、冲突保护；客户端的可操作检查仅用于交互反馈。

## 数据流与失败

- 执行前合并重复路径；父子同时选中只操作父路径，避免重复移动/删除。
- 禁止移入自身/后代；同目录移动不发请求；user 分区根为固定展示入口，不可被整根移动或删除。
- 移动逐项执行，冲突不覆盖，独立项目继续执行；部分成功后刷新树，保留失败项，错误提示包含项目名称。
- 删除消费接口的 deleted / failed 分项结果，不把 HTTP 成功等同于全部删除成功。
- 成功移动同步已打开文件和后代文件的预览路径；成功删除关闭对应预览，失败项目维持原路径。
- 写操作期间阻止重复提交；环境切换或卸载后不继续调度旧批次，也不将旧结果应用到新环境。
- 拖入本地文件继续走原有上传流程；文件服务不可用时保留陈旧提示并禁用改动。

## 验收

- 单选预览、修饰键多选、Shift 范围、右键保留/替换选择、菜单与取消确认。
- 单项/多项/跨分区拖动、根目录与空目录落点、父子去重、同名冲突、自身/后代保护。
- 部分失败、重复提交、切换环境与异步完成；预览路径同步；外部拖入上传不回归。
- 运行局部测试、bun run fastcheck、bun run precheck 和 bun run build:web。

## 回滚

本次只调整浏览器端交互与现有 API 调用，可按整组代码变更回退；无需迁移或数据补偿。已完成的文件移动和删除属于用户操作，不在代码回滚中逆向执行。
